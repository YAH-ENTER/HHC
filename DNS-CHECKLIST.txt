SECTION 3 - ANTI-SPOOFING (optional, recommended - no mail hosting needed)
--------------------------------------------------------------------------------
Because henryheatandcool.com sends no mail, you can publish records that
tell the world so. This stops spammers forging "from" addresses at your
domain, which protects the business name.

[ ] 3.1  SPF - hard fail everything.
         Host/Name: @     Type: TXT
         Value:  v=spf1 -all
         Only ONE SPF record per domain. If one already exists, do not add
         a second - edit it.

[ ] 3.2  DMARC - reject.
         Host/Name: _dmarc     Type: TXT
         Value:  v=DMARC1; p=reject; rua=mailto:Henryfunes0625@yahoo.com

[ ] 3.3  Optional - null MX (RFC 7505), declares the domain accepts no mail.
         Host/Name: @     Type: MX     Priority: 0     Value: .
         WARNING: only add this if you are sure you will never want
         info@henryheatandcool.com. It is a deliberate dead end.

[ ] 3.4  IF you later want info@henryheatandcool.com forwarding to the
         Yahoo inbox: that needs real MX records from an email provider,
         and items 3.1-3.3 must be revised at the same time (SPF and DMARC
